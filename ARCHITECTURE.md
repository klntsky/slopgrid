# Architecture

The React client uses TanStack Router for creation, grid history, settings, and grid routes, and TanStack Query for API state. A progressive questionnaire preserves previous answers and stores its in-progress form in sessionStorage across OAuth redirects. Grid pages use EventSource to receive server snapshots, including draft text while text generation streams. SVG drafts are completed locally for a disposable image preview: open elements and quoted attributes are closed, unfinished attribute names are omitted, and trailing partial entities are dropped. The browser decodes each candidate as an image before replacing the last valid preview. These changes never modify the stored final SVG; other text formats show escaped draft text. Persisted revision numbers prevent late HTTP responses from overwriting newer SSE state. Images and SVG render directly as image elements; HTML and Markdown previews use sandboxed iframes. Only HTML previews allow scripts. Grid pages render their title, pause/resume control, accessible progress bar, and action buttons into a header slot through a React portal. The progress bar spans the bottom of the header, with a moving, pulsing spark during generation and reduced-motion support. The shell fills the viewport and gives the remaining space to the grid scroll container. Small grids stretch their cells to fill that space, while larger grids scroll with sticky column, row, and corner headers. The corner labels each axis separately.

The Express server serves the built client in production and Vite middleware in development. `server/domain.ts` validates grid inputs, expands their Cartesian product, substitutes prompt variables literally, and validates generated static bundles. `server/provider.ts` combines the OpenRouter text and dedicated image-model catalogs, streams text through the AI SDK OpenRouter provider, optionally reviews a draft in a second AI SDK call, and generates images through the provider's image API. Reported USD costs are stored with each cell's token usage and summed across draft and review only when both charges are available. Text costs come from provider metadata; a scoped fetch wrapper preserves image response costs because the installed image adapter drops that field. Missing charges remain unknown rather than being treated as zero, and costs cover the successful attempt rather than aborted or failed requests.

`server/store.ts` stores grid snapshots, sessions, and immutable output records in SQLite with WAL enabled. Output-host lookups use a primary-key query rather than scanning grids. Each session owns grids through an opaque cookie token. OpenRouter PKCE verifiers and state are server-side; the callback checks state and a ten-minute deadline before exchanging the code. The resulting key is encrypted using AES-256-GCM. Neither keys nor ownership tokens appear in API grid responses.

`server/jobs.ts` schedules cells across all active grids using a shared worker pool. The configured maximum defaults to 100. Each available slot goes to a browser-session owner with the fewest active cells, with ties resolved by allocation history. Capacity is never reserved, and fair allocation never cancels active calls. Completed cells are skipped on every resume or retry. A manual pause aborts that grid’s active requests, discards partial drafts, and stops queued cells. Canceled attempts keep their slots until they settle, and late chunks or results are ignored; resuming cannot start the same cell twice. Billing and authentication failures pause queued work across the owner’s active grids without aborting its other in-flight calls. Other failures mark the affected cell as retryable. Parallel cells mutate one canonical grid object, so retries during in-flight work preserve completed results. Updates are persisted before SSE notification; draft updates are throttled per grid. A restart marks running grids paused and interrupted cells pending. Generation resumes only through an owner-authorized retry. Publishing requires every cell to be complete and freezes further retries.

Each cell receives a random 192-bit output identifier. HTML bundles use a separate hostname formed from that identifier and an environment-configured suffix beginning with a hyphen. Host matching accepts only the configured single-label pattern and exact cell identifier. The iframe CSP uses a whole-label wildcard for the HTML hosts’ parent domain, since CSP does not support partial-label wildcards. Host dispatch runs before JSON parsing, session cookies, API routes, or frontend serving. HTML hosts serve only that bundle's validated files, and `/api` cannot reach application handlers there. Their CSP sandbox omits `allow-same-origin` while allowing scripts and static assets; connections, forms, and cookie access are blocked, including when opened in a separate tab.

Images, SVG, and Markdown use `/outputs/:id` on the application host. Images are served as image bytes rather than HTML wrappers. SVG is served as `image/svg+xml` and previewed through an image element, which disables scripts and external resources. Direct visits to the SVG output URL retain the restrictive response CSP. Markdown is rendered with raw HTML escaped. These responses bypass session middleware, set no cookies, and have a CSP sandbox without script permission. The application cookie remains host-only and uses the `__Host-` prefix under HTTPS. HTML bundles cannot be fetched through the application output route, and the HTML host handler serves no other output formats.

Unpublished grids require their owner session for API access. Output URLs themselves are bearer capabilities and are readable without that cookie; random identifiers make their URLs unguessable. Published grids are publicly readable and retain the original owner for display controls. All mutations check ownership and reject cross-origin browser requests. The server limits API traffic, creation, retries, active workers, and SSE connections. Worker registries, listeners, rate counters, and model caches live in one process; SQLite retains results and credentials across process restarts.
