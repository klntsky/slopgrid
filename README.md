# slopgrid

Compare generated outputs in a grid. Choose models, thinking effort, prompt variables, or harnesses, then generate SVG, Markdown, static websites, or images using your OpenRouter account.

## Create a grid

1. Select **Create a grid** in the navigation bar, then choose the output format.
2. Choose what rows and columns represent, then select their values. Filter model lists by name or ID to find the models you want to compare. For prompt variables, enter one value per line. Image grids support models and prompt variables.
3. Enter your prompt. Use `$VARIABLE_ROW` and `$VARIABLE_COLUMN` to insert each cell's row and column values when those dimensions are prompt variables. Each enabled variable must appear in the prompt before you can generate.
4. Connect OpenRouter and select **Generate**.

When model, thinking effort, or harness is not a dimension, its selection applies to the whole grid. **Single pass** makes one request per cell. **Draft and review** generates a draft and makes a second request to check and revise it. A grid can contain up to 64 outputs, with up to eight values per dimension.

## Watch generation

The grid updates as generation progresses. Completed outputs remain available when you reload the page. Row and column headers stay visible as you scroll. Select **Open output** to view a result in a separate tab.

If OpenRouter reports a billing problem, check your credits and key spending limit, then select **Retry unfinished cells**. You can close the popup and retry later. Completed cells are saved and are never regenerated by retries. If OpenRouter rejects your key, reconnect OpenRouter. Work interrupted by a server restart also requires an explicit retry.

## Publish and share

Select **Publish grid** after all cells finish, then **Copy link** to share the grid. Publishing makes the prompt, dimensions, and outputs accessible to anyone with the link. Published grids cannot be changed.

Open **Your grids** in the navigation bar to find grids created in this browser. Selecting the slopgrid logo opens **Your grids** when you have created at least one grid, or the creation form when you have none. Keep that browser's cookies: ownership is tied to a 30-day browser session, with no separate slopgrid login or cross-device account. Each completed output has an unguessable URL that can be opened directly; anyone who receives that output URL can view it, even before the grid is published.

## OpenRouter settings

Open **Settings** to connect, reconnect, or disconnect OpenRouter. Generation uses your account's credits. Disconnecting prevents further requests; an already-running request may still finish.

Generated websites run in an isolated sandbox. Static HTML, CSS, and JavaScript are supported; server-side code, network requests, forms, and browser cookies are blocked. Images and SVG render as images, with SVG scripts and external resources disabled. Opening an SVG output directly retains script and cookie restrictions, while Markdown previews also disable scripts and cookie access. Raw HTML in Markdown is shown as text.
